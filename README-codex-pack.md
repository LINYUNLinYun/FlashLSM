# LSM Codex Pack

This pack contains project-level Codex instructions and reusable skills for an LSM-Tree KV Store course project.

## How to Use

Copy these files into the root of your project:

```text
AGENTS.md
.codex/
docs/
```

Then open Codex in the project root.

## Included Skills

- `lsm-architecture`
- `lsm-implementation`
- `lsm-debugging`
- `lsm-benchmark-report`

## Suggested Prompts

```text
Use lsm-architecture to review my current project structure.
```

```text
Use lsm-implementation to implement MemTable and WAL first.
```

```text
Use lsm-debugging to investigate why delete returns the old value after flush.
```

```text
Use lsm-benchmark-report to design experiments for my final report.
```
